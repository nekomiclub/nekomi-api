# NEKOMI API
nekomi-api is an nekomi.club backend. Simple, isn't it?

> [!IMPORTANT]
> In DevelopmentMode env.PORT will be changed into 80

## Setup Guide
1. Add .env file (see .env.example)
2. ```npm ci```
3. ```npm run start```
